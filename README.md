# 📊 Automação de Planilha Excel

Automação para leitura automatizada de uma planilha Excel utilizando Java e Selenium.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java
- **IDE:** IntelliJ IDEA
- **Gerenciador de Dependências:** Maven
- **Biblioteca:** Selenium
- **Versionamento:** Git
